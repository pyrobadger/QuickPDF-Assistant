# QuickPDF Assistant

## TECH STACK
- Supabase PostgreSQL

## Prerequisites
- Node.js (v12 or above)
- Supabase account
- NPM or Yarn for package management

## Configuration
1. Create a new Supabase project and obtain your connection details.
2. Replace the `SUPABASE_URL` and `SUPABASE_KEY` in your configuration file with your Supabase project’s details.
3. Once configured, ensure to test the connection before proceeding with application use.

## Installation
1. Clone the repository.
2. Install the dependencies with `npm install` or `yarn install`.
3. Start the application using `npm start` or `yarn start`.
